# JavaScript / TypeScript / Svelte

- Use snake_case for variable & function names, not camelCase.
- Annotate types explicitly where TypeScript allows it: `const page_size: number = 60;`.
- Svelte: render self-closing tags without a space before the slash: `<Header/>`, not `<Header />`.
